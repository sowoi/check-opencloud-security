Every command-line option the plugin accepts, what it defaults to, and the environment variable that sets the same thing. This lives on its own page because it is a lookup table rather than something to read: the main README is the guided tour, and this is the index at the back.

Precedence between the three ways of setting anything is always the same: command-line flag > environment variable > configuration file > default. See Configuration file and secrets for the file, and Environment variables for the naming rules.

Settings with no flag of their own

The TLS expiry window, the debug-port list and the advisory sources have no command-line flag. They are configured through the configuration file or their COS_SCANNER_* environment variables, and config/check-opencloud-security.example.yml lists every one of them with a comment.
