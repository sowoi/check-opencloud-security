What this server keeps

Short answer: the scan, for {{ result_ttl_minutes }} minutes, in memory.

Retention

While a scan is alive

The address you submit, the checks you chose to waive and the result live in memory for {{ result_ttl_minutes }} minutes, under a key derived from your scan's random identifier, and are then dropped by the store itself. The operational log records that a scan was created, started and finished, identified by that random identifier alone - not the address, not the result and not your IP address, which is only ever counted as a one-way fingerprint for rate limiting.

Prefer to run it yourself? The same scanner is a command line check and a Python package. Nothing here talks to a third-party service in either case.
