For AI agents

This service is meant to be usable by software that was not written for it. Everything an agent needs is published, in the open, without an account: what the API can do, how its calls combine into a task, and a way to run that task directly.

Start from one address

  • Discovery - /.well-known/ai.json names all of the below, with absolute URLs. Start here.
  • OpenAPI - /openapi.json, every operation with its real status codes and response shapes.
  • Arazzo workflows - /arazzo.json, the lifecycle of a scan: submit, poll, detect completion, export.
    • {% if mcp_enabled %}
  • MCP - {{ mcp_url }}, a Model Context Protocol endpoint over streamable HTTP. Tools: scan_instance, scan_instances, get_scan_result, export_scan and erase_instance_data. scan_instance does the whole task - submission, waiting and result - in one call. It answers the protocol rather than a browser, so it is an address to configure rather than a page to open.
    • {% endif %}

The three documents describe one service from three angles: OpenAPI says what the API can do, Arazzo says how those operations combine into a task{% if mcp_enabled %}, and MCP hands that task to an agent as a tool it can call{% endif %}. They are generated from the same code the server runs, so none of them can quietly go out of date.

Wiring it into a client

Most agent tools take a URL and a transport. This one is streamable HTTP, with no authentication and no account: 

{"type": "http", "url": "{{ mcp_url }}"}

Worked configuration for Claude Code, Claude Desktop, GitHub Copilot in VS Code and the CLI, Cursor, Zed and Windsurf - against this deployment or one of your own - is in the MCP guide.

{% endif %}

The same rules as everybody else

The rules are the same for an agent as for anybody else. A scan is asynchronous and the uuid is the only way back to it; a 429 is an invitation to slow down rather than a refusal; and if you are checking more than a handful of instances, please run the scanner yourself - it is the same code, on your machine, with no limits.
